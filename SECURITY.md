# Security

Report a vulnerability privately through GitHub's security advisories:
https://github.com/ilanoh/botpassport/security/advisories/new

Please do not open a public issue for it.

A wrong address in a list matters too: botpassport copies each operator's published list, so an address that does
not belong to the operator means the operator's list is wrong or botpassport parsed it wrongly. Report it the
same way, with the address and the list URL.
